Using the .mat in MATLAB

Every message type in the log becomes one variable: a 1×1 struct whose fields are the message’s columns. Numbers are row vectors with one entry per message; text fields are char matrices with one row per message.

MATLAB
load('sample-flight.mat')   % ATT, GPS, BARO, ...
t = double(ATT.TimeUS) / 1e6;  % int64 µs to s
plot(t, ATT.Roll, t, ATT.DesRoll)
legend('Roll', 'DesRoll'); xlabel('Time (s)'); ylabel('deg')

% text fields: char matrix, one row each
names = strtrim(cellstr(PARM.Name));
PARM.Value(strcmp(names, 'WP_LOITER_RAD'))

% Lat/Lng are already in degrees
geoplot(GPS.Lat, GPS.Lng)

How it works

The converter is a small JavaScript program that ships inside this page. Once the page has loaded it needs no network connection.

  • Read

    Same parser rules as pymavlink

    Messages are found by their A3 95 header and decoded with the log’s own FMT definitions. Corrupt bytes and a truncated final message are skipped the way pymavlink’s DFReader skips them.

  • Write

    Same file as scipy.io.savemat

    The output is a MATLAB v5 MAT-file. Field order, data types, string padding and values match the Python desktop tool. Without compression the bytes are identical apart from the header date.

  • Extra

    Pick what you need

    Untick message types you don’t need for a smaller file. Compression is on by default, and MATLAB’s load reads compressed files natively. Quick look plots any numeric field before you download.

Questions

How do I convert an ArduPilot .bin log to a MATLAB .mat file?

Drop the .bin file on this page, untick any message types you don’t need and press Download .mat. In MATLAB, load('yourlog.mat') puts every message type (ATT, GPS, IMU, BARO, RCOU and so on) in the workspace as a struct.

Which logs are supported?

DataFlash logs from ArduPilot firmware (ArduCopter, ArduPlane, ArduRover, ArduSub) on Pixhawk, Cube and similar flight controllers. Use the .bin from the SD card or one downloaded with Mission Planner, QGroundControl or MAVProxy, or a text .log exported by Mission Planner. PX4 .ulg logs and MAVLink .tlog telemetry logs are not supported.

Is my flight log uploaded anywhere?

No. The page reads and converts the file with JavaScript on your own computer. Nothing is sent to a server, and once the page has loaded it works without an internet connection.

Can I open the .mat file in Python or GNU Octave?

Yes. It is a standard version 5 MAT-file. In Python use scipy.io.loadmat('log.mat'); in GNU Octave use load('log.mat'). Switch compression off if a reader needs an uncompressed file.

How do I get the time in seconds?

Every message has a TimeUS field: microseconds since the flight controller booted, stored as int64. Use double(ATT.TimeUS)/1e6, or choose “double” under Integer fields before downloading.

How large a log can it handle?

Logs of several hundred megabytes work in desktop Chrome, Edge and Firefox; a 200 MB log takes about five seconds. Untick high-rate messages such as IMU or ISBD when you need a smaller file.
